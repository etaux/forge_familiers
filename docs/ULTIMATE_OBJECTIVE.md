# Objectif permanent — Posséder AETERNUM

## Principe

AETERNUM est la seule carte du rang **Ultime**. Elle représente l’objectif final de la Série Origine.

## Conditions

Le joueur doit avoir découvert les onze cartes de rareté Unique :

- CHRØMA–ZÉRO
- PRISMARA
- MERCUREL
- ABYSSALIS
- AXIOME–7
- HÉLION NACRÉ
- MIROLYNX
- ORACLE–Ω
- ASTRALITHE
- VESPERA–X
- BORÉAL PRIME

La découverte reste comptabilisée même si une carte Unique n’est plus disponible dans l’inventaire.

## Obtention

Lorsque la progression atteint 11/11, le bouton **Forger AETERNUM** devient actif dans l’onglet Albums. La forge :

- ne consomme aucune carte Unique ;
- ne coûte aucune monnaie ;
- ajoute une copie d’AETERNUM ;
- enregistre définitivement la découverte ;
- ne peut être utilisée qu’une fois.

## Protection

AETERNUM possède `tradable: false` dans le catalogue. Le serveur local refuse sa mise en vente. Sa valeur de recyclage est nulle et le dernier exemplaire est protégé.
